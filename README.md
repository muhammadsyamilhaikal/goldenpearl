# Golden Pearl Venue Hall Management System 🏰

**DSPD 2794 Project:** A complete and centralized venue hall booking and payment management system developed using PHP and MySQL. 

This system provides a seamless experience for customers to book event halls, while offering a comprehensive dashboard for administrators and staff to manage reservations, track payments, and oversee daily operations.

---

## 🌟 Key Features

The system is designed with a role-based access control (RBAC) architecture, catering to three different types of users:

### 1. Customer (Pelanggan)
* **Check Availability:** View real-time hall availability via an interactive calendar.
* **Make Reservations:** Book from 3 available packages (Meeting Room, Standard Hall, Grand Wedding Hall).
* **Payment Integration:** Upload payment proof and select payment methods (FPX, Card, DuitNow QR).
* **Automated Receipts:** Generate and print official booking receipts automatically once payment is verified.

### 2. Staff (Kakitangan)
* **Dashboard Monitoring:** Track total bookings and pending approvals.
* **Booking Management:** Approve or reject pending customer reservations.
* **Schedule Oversight:** View the hall schedule to prepare for upcoming events.

### 3. Administrator (Admin)
* **Full Access Control:** Oversee all system activities and comprehensive statistics.
* **Staff Management:** Register new staff accounts or remove existing ones.
* **Complete Booking Authority:** Manage all reservations, verify payments, and oversee the entire workflow.

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (Vanilla)
* **Database:** MySQL
* **Libraries:** FullCalendar (for availability checking)
